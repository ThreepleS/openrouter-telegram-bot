# Переменные окружения

Проект использует только `.env`. Файл `api.env` больше не используется и удалён.

Скопируй шаблон:

```powershell
Copy-Item .env.example .env
```

## Обязательные

| Переменная | Пример | Описание |
|---|---|---|
| `BOT_TOKEN` | `123456789:ABC...` | Токен Telegram-бота из @BotFather. |
| `ADMIN_ID` | `123456789` | Telegram ID администратора. Только этот ID имеет доступ к `/admin`. |

## Рекомендуемые

| Переменная | Пример | Описание |
|---|---|---|
| `DB_PATH` | `bot.db` | Путь к SQLite-базе. Относительный путь считается от корня проекта. |

## Опциональные

| Переменная | Пример | Описание |
|---|---|---|
| `PROXY` | `http://127.0.0.1:7890` | Прокси для Telegram polling. Обычно можно не задавать: aiogram session использует системные proxy/VPN настройки. |
| `OPENAI_API_KEY` | `sk-...` | Серверный ключ OpenAI. Если задан, используется вместо пользовательского ключа для моделей OpenAI. |
| `GEMINI_API_KEY` | `AIza...` | Серверный ключ Gemini. |
| `GROQ_API_KEY` | `gsk_...` | Серверный ключ Groq. |
| `HF_API_KEY` | `hf_...` | Серверный ключ Hugging Face. |

## Безопасность

- Не коммить `.env`.
- Не коммить `api.env`.
- Не выводи значения `.env` в чат, логи или отчёты.
- Для локальной разработки достаточно `BOT_TOKEN`, `ADMIN_ID` и `DB_PATH`.
- Пользовательские API-ключи хранятся в SQLite-записи пользователя, а не в `.env`.

## Пример `.env`

```env
BOT_TOKEN=
ADMIN_ID=
DB_PATH=bot.db

# Необязательно
# PROXY=http://127.0.0.1:7890
# OPENAI_API_KEY=
# GEMINI_API_KEY=
# GROQ_API_KEY=
# HF_API_KEY=
```
